# Student Management System 🎓

## 📌 Project Description

The Student Management System is a simple Java application used to manage student records. It helps users store, view, update, and delete student information efficiently.

## 🚀 Features

* Add student details
* View student records
* Update student information
* Delete student records
* Simple and user-friendly application

## 🛠️ Technology Used

* Java

## 📂 Project Structure

```text
StudentMangement/
└── Main.java
```

## ▶️ How to Run

1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Compile the program:
   `javac Main.java`
5. Run the program:
   `java Main`
